# 飞书联络与升级规则

更新时间：2026-06-11

## 目标

把飞书作为 AI副业实验室 的低打扰联络入口。日常执行由 Codex 自己推进；只有涉及账号安全、资金、公开发布、实名验证、平台处罚风险时才升级给 Jack。

## 当前状态

- 飞书已登录。
- 已创建飞书群：`So 副业实验室 运营中枢`。
- 已配置自定义机器人 webhook，本地通过 `.env.local` 读取。
- Codex 可以向飞书群发送项目摘要、最终发布包和风险提醒。
- 当前飞书只作为“出站通知”通道，不作为 Codex 读取 Jack 回复的入口。
- Jack 如需手机指挥，优先使用 GitHub Issue 手机指挥台。

## 通知分级

### P0 立即联系

必须暂停并联系 Jack：

- 平台要求实名、人脸、短信、邮箱验证码。
- 需要输入支付密码、银行卡、身份证、手机号等敏感信息。
- 发布页面出现违规、限流、处罚、申诉、账号异常提示。
- 需要公开展示收款码、联系方式或隐私资料。
- 需要花钱购买会员、域名、广告、工具或服务。

### P1 当天联系

可以先记录，晚些联系 Jack：

- 小红书笔记发布成功，需要 Jack 看最终链接。
- 出现具体评论、私信、合作咨询。
- 有用户索要模板、报价、定制服务。
- 网站或内容需要改定位、改名字、改头像背景。

### P2 不打扰

Codex 自己处理并写入复盘：

- 文案润色。
- 图片尺寸调整。
- GitHub/Vercel 常规维护。
- 飞书表格、复盘表、发布队列更新。
- 内容敏感词自查。
- 小规模素材整理。

## 飞书消息模板

### 发布成功

`【AI副业实验室】小红书第 X 篇已发布。标题：... 链接：... 下一次数据记录时间：...`

### 需要你确认

`【需要确认】当前操作涉及账号/实名/资金/公开发布风险，我已暂停。请处理：...`

### 数据复盘

`【数据复盘】发布 X 小时：曝光 ... 点赞 ... 收藏 ... 评论 ... 私信 ... 具体问题 ... 建议下一步：...`

### 用户反馈

`【用户反馈】收到一个具体需求：... 判断：继续/调整/停止。建议动作：...`

## 合规底线

- 不承诺收益。
- 不教违规玩法。
- 不碰投资建议。
- 不虚构案例、订单、收入。
- 不公开收款码、手机号、身份证、真实姓名等隐私。
- 发布前保留人工/自动检查记录。
