## 通知分级

### P0 立即联系

必须暂停并联系 Jack：

- 平台要求实名、人脸、短信、邮箱验证码。
- 需要输入支付密码、银行卡、身份证、手机号等敏感信息。
- 发布页面出现违规、限流、处罚、申诉、账号异常提示。
- 需要公开展示收款码、联系方式或隐私资料。
- 需要花钱购买会员、域名、广告、工具或服务。

### P1 当天联系

可以先记录，晚些联系 Jack：

- 小红书笔记发布成功，需要 Jack 看最终链接。
- 出现具体评论、私信、合作咨询。
- 有用户索要模板、报价、定制服务。
- 网站或内容需要改定位、改名字、改头像背景。

### P2 不打扰

Codex 自己处理并写入复盘：

- 文案润色。
- 图片尺寸调整。
- GitHub/Vercel 常规维护。
- 飞书表格、复盘表、发布队列更新。
- 内容敏感词自查。
- 小规模素材整理。

## 飞书消息模板

### 发布成功

`【AI副业实验室】小红书第 X 篇已发布。标题：... 链接：... 下一次数据记录时间：...`

### 需要你确认

`【需要确认】当前操作涉及账号/实名/资金/公开发布风险，我已暂停。请处理：...`

### 数据复盘

`【数据复盘】发布 X 小时：曝光 ... 点赞 ... 收藏 ... 评论 ... 私信 ... 具体问题 ... 建议下一步：...`

### 用户反馈

`【用户反馈】收到一个具体需求：... 判断：继续/调整/停止。建议动作：...`

## Jack 需要做的一次性设置

1. 飞书中新建群：`AI副业实验室-运营中枢`。
2. 群设置里添加自定义机器人。
3. 复制 webhook 地址。
4. 把 webhook 发给 Codex，或保存为本机环境变量 `FEISHU_WEBHOOK_URL`。
5. 如果机器人启用了签名校验，同时保存 `FEISHU_WEBHOOK_SECRET`。

## 合规底线

- 不承诺收益。
- 不教违规玩法。
- 不碰投资建议。
- 不虚构案例、订单、收入。
- 不公开收款码、手机号、身份证、真实姓名等隐私。
- 发布前保留人工/自动检查记录。
