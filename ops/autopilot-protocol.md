# AI副业实验室自动驾驶协作协议

更新时间：2026-06-10

## 协作目标

让 Codex 承担项目的日常推进工作，Jack 只在关键节点做确认。目标不是承诺收益，而是用持续实验提高赚钱概率：每天有产出、每周有复盘、每月决定继续或换方向。

## 默认工作模式

每天上午 9:30，Codex 主动生成当天工作包：

1. 今日目标
2. 昨日/上次进展
3. 今天可自动完成的事项
4. 需要 Jack 确认的事项
5. 合规风险检查
6. 下一步建议

## Codex 可以自动完成

- 小红书标题、正文、话题、封面方案
- 网站文案与工具优化
- 模板包、清单、报价单、客户问卷
- 飞书/Excel 运营表更新
- GitHub 提交、Vercel 部署检查
- 内容敏感词与合规自查
- 市场调研、竞品拆解、案例复盘
- 每日工作包和每周复盘

## 必须 Jack 确认

- 公开发布到小红书、抖音、朋友圈等账号
- 使用真实头像、姓名、手机号、微信号、收款码
- 涉及实名、人脸、短信、邮箱验证码
- 涉及付款、投流、购买工具、开会员
- 涉及客户报价、收款、退款、承诺交付
- 涉及医疗、金融、投资、法律、功效类敏感内容
- 平台出现违规、限流、申诉、账号异常提示

## 项目底线

- 不承诺收益
- 不制造焦虑
- 不教灰产
- 不虚构数据、案例、订单
- 不公开隐私和收款码
- 不用 AI 冒充真人体验
- 先验证需求，再做付费产品

## 赚钱路径

当前主线：

AI副业实验室：真实验证普通人可执行的 AI 副业项目，沉淀工具、模板、复盘和低价服务。

优先变现顺序：

1. 免费内容获取反馈
2. 免费模板获取具体需求
3. 低价服务包试单
4. 标准模板包或工具
5. 月度服务或订阅

## 每周复盘问题

- 本周发布了几条内容？
- 有没有具体评论或私信？
- 有没有人愿意提供真实场景？
- 哪个标题/封面/话题表现最好？
- 是否出现付费信号？
- 下周继续、缩小方向，还是换实验？

## Jack 的最小参与

每天只需要做三类动作：

1. 确认是否发布
2. 提供平台验证码或账号权限
3. 回复真实客户或用户消息

除此之外，默认由 Codex 先做出版本，再交给 Jack 判断。
