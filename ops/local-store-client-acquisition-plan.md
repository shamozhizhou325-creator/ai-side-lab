# 本地门店内容包 获客验证计划

更新时间：2026-06-11

目标：验证“本地门店 7 天内容启动包”是否有真实咨询和付费可能。

## 阶段 1：先不主动骚扰

当前不做大规模私信。

原因：

- 账号刚启动，信任资产不足。
- 主动私信容易像营销。
- Jack 还没有确认对外报价和收款流程。

先做：

- 在 003 中展示虚拟样例。
- 网站放出模板入口。
- 准备客户可读样例页。
- 等评论或私信出现后再进入初筛。

## 阶段 2：低风险获客入口

可用入口：

1. 小红书 003 评论区
2. 主页简介中的网站链接
3. 朋友/熟人推荐的真实门店
4. Jack 主动指定的本地行业样例

第一批行业优先级：

1. 咖啡店
2. 美甲/美睫
3. 宠物店
4. 健身工作室
5. 摄影工作室
6. 小餐饮

暂缓行业：

- 医美
- 教培提分
- 金融投资
- 医疗健康功效
- 需要强资质背书的行业

## 阶段 3：初筛标准

适合体验版：

- 有真实门店。
- 有基础照片素材。
- 愿意自己发布。
- 接受不承诺涨粉、到店、成交。
- 能提供 7 天后反馈。

不适合体验版：

- 要求保证效果。
- 要求代发账号。
- 要求虚构评价或销量。
- 不愿意提供基础信息。
- 行业敏感或素材风险高。

## 阶段 4：谈单流程

1. 收到咨询。
2. 使用 `templates/free/local-store-service-replies.md` 初筛。
3. 使用 `templates/free/local-store-intake-questionnaire.md` 收集信息。
4. Codex 生成是否适合体验版的判断。
5. Jack 确认是否报价。
6. Jack 确认收款。
7. Codex 交付第一版。
8. 7 天后复盘。

## 阶段 5：成交判断

出现以下任一信号，说明方向值得继续：

- 有人问能不能帮他做。
- 有人主动提供门店信息。
- 有人问价格。
- 有人收藏并评论具体行业。
- Jack 身边有人愿意给真实门店样例。

## 当前最小动作

不打扰 Jack 的情况下：

- 完成客户可读样例页。
- 完成 003 内容发布准备。
- 等 Jack 确认是否发布 002。

需要 Jack 的最小动作：

- 如果身边有低风险本地小店，可以只告诉 Codex 一个行业，不需要给隐私信息。
